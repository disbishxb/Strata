# 用户可见更新

> 只写用户能感知的变化；相对基线 Strata 1.0.0。发布时从这里取摘要。

## 1. 安装与更新应用
- 新增 Shizuku 安装后端：可通过 Shizuku 安装 APK。
- 新增 Dhizuku 安装后端：可通过 Dhizuku（设备所有者）安装 APK。
- 新增第三方安装器：可把 APK 交给指定安装器应用完成安装。
- 新增安装后端优先级：可拖拽排序 Root / Shizuku / Dhizuku，按顺序选用第一个可用的。
- 新增安装后端状态提示：显示各后端是否可用及原因。
- 新增签名校验开关说明与第三方安装器设置页。
- 新增 `.apk.1` 等非标准后缀的安装兼容处理（复制为 `.apk` 再装）。

## 2. 应用管理
- 新增“应用控制”面板：强制停止、启用/停用、隐藏/取消隐藏、挂起/取消挂起。
- 新增后端选择：自动 / Root / Shizuku / Dhizuku / 特权系统应用。
- 新增 Dhizuku 挂起/恢复。
- 新增“本应用”标记与自我保护提示。
- 新增应用列表过滤：全部/用户/系统/可启动/受限/调试签名。
- 新增受限类型过滤：禁用/隐藏/挂起。
- 新增排序：名称/包名/安装时间/更新时间/大小；升降序。
- 新增签名信息查看与旋转密钥提示。
- 新增权限引导：应用列表访问权限说明、重新申请、打开设置。

## 3. 文件浏览与操作
- 新增 STGX 自定义语法与图标：可为扩展名指定语法、图标、颜色。
- 新增语法（STGX）管理页：导入、导出、内置列表、预览、排序、失败区。
- 新增分卷 `.001/.002/...` 自动合并打开。
- 新增文件列表导出（目录/归档/多选），支持绝对/相对路径、递归、格式与编码。
- 新增“仅此文件夹”排序选项。
- 受限 Android 目录（Android/data、Android/obb）无权限时，界面会列出本应用自己的私有文件夹，可直接打开。
- 从该私有文件夹返回时回到对应的受限目录界面，不再跳到 Android/。
- 新增 root 模式 / Shizuku 下的受限目录访问。
- 新增远程编辑检测与上传提示。
- 新增保险库相关操作入口与提示。
- 新增长按菜单可自定义（显示/隐藏/排序）。
- 新增工具栏可自定义（底栏/选择栏/长按）。
- 新增抽屉盒：把侧栏项目“收纳”到 Storage box。

## 4. 打开方式
- 新增 STGX 文件打开动作面板：编辑、管理、安装/替换/卸载。
- 新增更多内置打开器与默认打开设置。
- 新增“打开为”类型选择（自动/文本/图片/音频/视频/任意）。

## 5. 编辑器
- 新增 STGX 语法选择与高亮。
- 新增颜色拾取与插入/替换。
- 新增 Process Text（用其他应用处理选中文本）。
- 新增编码选择与保存编码。
- 新增行尾选择与保存。
- 新增大文件分页编辑与只读提示。
- 新增外部变更检测与重载/保留提示。
- 新增查找替换、正则、整词、大小写。
- 新增符号栏、缩进参考线、粘性滚动、括号高亮等选项。
- 退出编辑器时自动收起输入法。

## 6. 设置
- 新增“安装方法”“安装优先级”“第三方安装器”设置组。
- 新增“长按菜单”设置页。
- 新增“抽屉盒”设置页与侧栏预览。
- 新增“启动位置”设置页：左/右窗独立设置。
- 新增 Dhizuku 访问设置。
- 新增系统特权说明。
- 新增支持页二维码与 fork 维护者信息。
- 新增导出/导入设置（含新字段）。
- 新增中文/波斯语/俄语导出字符串。

## 7. Termux
- 新增“命令运行器”：选择工作目录、输入命令、查看输出、复制、取消。
- 新增 Termux 安装/权限/外部应用/存储的分步引导。
- 新增语言/项目模板与安装提示。
- 新增 SSH 终端与 openssh 安装提示。

## 8. 其他
- 新增 Python 图标与配色。
- 新增更多插画（未知、警告）。
- 新增中文/波斯语/俄语导出字符串。
- 新增权限：组件启用状态、强制停止、挂起应用、已安装应用列表。
- 新增日语界面：设置 → 语言中可选择「日本語」，Android 13+ 系统「应用语言」同样支持；全部 14 个界面模块均已翻译。
